# TDD Red Phase

Write a failing test for: $ARGUMENTS

## Instructions

1. Write the simplest failing test that defines the requested functionality
2. Use meaningful test name that describes behavior (e.g., "shouldSumTwoPositiveNumbers")
3. Make the test failure clear and informative
4. Run the test to confirm it fails with the expected reason
5. Do NOT write any implementation code yet

## Output

- Show the failing test code
- Show the test failure message
- Confirm we are in RED phase
