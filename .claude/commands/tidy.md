# Tidy First - Structural Refactoring

Apply structural improvements without changing behavior.

## Instructions

1. Confirm all tests are currently passing (GREEN state required)
2. Identify structural improvements needed:
   - Remove duplication
   - Improve naming
   - Extract methods
   - Move code to better locations
3. Make ONE structural change at a time
4. Run tests after each change to verify behavior is unchanged
5. Continue until code is clean

## Tidy First Rules

- ONLY structural changes (no behavioral changes)
- Never mix structural and behavioral changes
- Run tests before AND after each change
- If tests fail, revert immediately

## Common Structural Changes

- Rename variable/method/class
- Extract method
- Inline method
- Move method
- Extract class
- Remove dead code
