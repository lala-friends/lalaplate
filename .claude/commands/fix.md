# Fix Defect with TDD

Fix a defect using TDD approach: $ARGUMENTS

## Instructions (Kent Beck's Defect Fix Process)

1. **API-Level Test**: Write a failing test at the API level that demonstrates the bug
2. **Smallest Test**: Write the smallest possible test that replicates the problem
3. **Fix**: Implement the fix to make both tests pass
4. **Verify**: Run all tests to ensure no regressions
5. **Report**: Describe what was broken and how it was fixed

## Output

- Show the failing test(s) first
- Show the fix implementation
- Show all tests passing
- Summarize the root cause
