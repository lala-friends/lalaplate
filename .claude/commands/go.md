# TDD Go Command

Execute the next TDD cycle from plan.md.

## Instructions

1. Read plan.md and find the next unmarked test (test without checkmark)
2. Write the failing test (Red phase)
3. Run the test to confirm it fails
4. Implement the minimum code to make it pass (Green phase)
5. Run all tests to confirm they pass
6. Mark the test as complete in plan.md with a checkmark
7. Report what was done

## Constraints

- Write only ONE test at a time
- Implement only enough code to make that test pass
- Do not add extra functionality
- Do not refactor yet (save for /tidy command)
