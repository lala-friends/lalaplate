# Run Tests

Run all tests and report results.

## Instructions

1. Run the full test suite
2. Report results clearly:
   - Total tests
   - Passed tests
   - Failed tests (with details)
3. Indicate current TDD phase:
   - RED: Tests failing (ready to implement)
   - GREEN: All tests passing (ready to refactor or add new test)

## Output Format

```
Test Results: X passed, Y failed
Current Phase: RED/GREEN

[If failures exist, show failure details]
```
