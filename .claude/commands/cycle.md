# Full TDD Cycle

Execute a complete Red-Green-Refactor cycle for: $ARGUMENTS

## Instructions

### Phase 1: RED
1. Write a failing test for the specified functionality
2. Run test to confirm it fails

### Phase 2: GREEN
3. Implement minimum code to pass the test
4. Run all tests to confirm passing

### Phase 3: REFACTOR (if needed)
5. Identify any structural improvements
6. Apply one refactoring at a time
7. Run tests after each refactoring

### Phase 4: COMMIT
8. If structural changes were made, commit them first
9. Commit the behavioral changes

## Output

Show each phase clearly:
- RED: Failing test and error message
- GREEN: Implementation and passing tests
- REFACTOR: Changes made (if any)
- COMMIT: Commit messages created
